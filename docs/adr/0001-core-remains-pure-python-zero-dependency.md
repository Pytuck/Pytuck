# 核心运行时保持纯 Python 零依赖

Pytuck 的首要使用场景是 Ren'Py 等受限 Python 环境，因此核心运行时必须始终保持纯 Python、默认安装零外部依赖。第三方依赖只能用于显式启用的扩展能力，不能成为核心格式、基础数据操作或安全读取路径的前提；在正常环境中，用户本就可以选择 SQLAlchemy、SQLite 等成熟方案，所以优化工作不得以牺牲这一定位为代价，也不为引入外部密码学依赖而推动 PTK8。

## Consequences

- `dependencies` 必须继续为空；扩展依赖只能放入可选 extras。
- 核心功能必须能在不具备第三方包和原生扩展的环境中运行。
- 文件格式与加密能力优先在 PTK7 兼容边界内加固，不因采用外部 AEAD 或 KDF 库而升级核心格式。
- 架构、正确性和性能优化应优先服务受限环境，而不是追求替代成熟数据库。
